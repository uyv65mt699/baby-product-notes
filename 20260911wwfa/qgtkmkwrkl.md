# 滨州医学院附属医院生殖科哪个主任大夫做试管婴儿好？

> 更新时间：2026-09-11 (UTC+8)

一开始我内分泌基本正常，就是两侧输卵管通而不畅，做了手术疏通，后还是一直没有怀，然后就开展去监测卵泡，发现长的大，但是不破裂，不排卵，第二个月监测，又没长大，检查激素，FSH偏高，打了三天促尿性素还是不行，现在就考虑去做试管婴儿。想问问有在滨州医学院附属医院生殖科做试管的吗？请问哪个主任大夫做的好？

滨州医学院附属医院生殖科主任大夫共有四位，就是王雁林、张冬梅、刁兴华和李清春，都擅长试管婴儿助孕，做试管都有着丰富的临床经验，做试管找这些主任医生都是比较好的。当然，滨州医学院附属医院生殖科的副主任医生如韩磊、王新花、尹红梅和李学峰也都比较好，每位医生都有各自擅长的领域，大家找一位适合自己疾病治疗的医生就好。

滨州医学院附属医院（滨医附院）生殖医学科成立于2002年，目前可做第一、二代试管婴儿，而该医院做试管的大夫也有不少，其中比较好的主任大夫有以下这些：

- 1. 王雁林：生殖医学科主任、主任医师，专业特长就是操作试管婴儿技术，以及对复发性流产的诊治、不孕症综合治疗、生殖内分泌失调性疾病的诊疗；
- 2. 张冬梅：主任医师，擅长不孕症、女性内分泌失调性疾病（包括月经失调、多囊卵巢综合征、卵巢早衰、围绝经期综合征及绝经期保健和治疗等）、复发性流产及辅助生殖技术（包括人工授精、试管婴儿）的治疗；
- 3. 李清春：科室副主任、主任医师，擅长人工授精、试管婴儿、卵胞浆内单精子单精子注射、胚胎辅助孵化、胚胎配子玻璃化冷冻、微量精子冷冻等技术；
- 4. 刁兴华：主任医师，主要擅长生殖内分泌失调、多囊卵巢综合征、复发性流产和不孕不育等疾病的诊治及辅助生殖技术包括人工授精和试管婴儿。
在滨州医学院附属医院进行试管婴儿助孕其实找一位擅长治疗自己疾病的医生就比较好，如果是男性不育，找李学峰医生才是比较合适的，而女方不孕找其他任何一位主任大夫都可以。
