# 微信服务平台使用指南

> 更新时间：2026-09-17 (UTC+8)

欢迎使用**佛山市妇幼保健院**微信服务号。

**主要功能：**门诊挂号缴费、住院缴纳按金、车位信息、候诊信息、取药提醒、报告查询等。

请阅读下文，带您了解如何使用我院微信公众平台提供的服务。

**特别说明：**

- 
每天23:45至次日00:15暂停使用，系统将进行例行维护。

- 
**每天****06:30**更新号源，请知悉此放号时间。（2016年6月18日起实施）

- 
请勿将个人信息（姓名、卡号、证件号和手机号等）提交给他人使用，以免被他人利用，影响本人的就诊信用。请先阅读了解《门诊就诊患者信用制管理办法》

如何办理健康卡

- 
**线上办理：**点击菜单【个人中心】->【我要办卡】，点击“立即填写信息办卡”，然后输入**姓名**、**身份****证号码和联系地址，**最后点击“确认”，根据系统指引操作完成办理佛山健康卡的业务。（**注：**仅适用于已办理居民身份证的用户使用）

- 
**线下办理：**凭相关证件（出生证、户口薄、居民身份证、护照等）原件到我院或您附近的联网医院进行实名制办理佛山健康卡。

如何绑定健康卡

- 
点击菜单【个人中心】->【我的信息】，点击“添加绑定”，然后输入**姓名**、**健康卡号**（佛山健康卡、国家居民健康卡）、**证件号**（身份证号、出生证号、护照号等）、**手机号**和**验证码**，最后点击“确定提交”进行身份验证，系统校验通过后完成绑卡，绑卡后可使用预约挂号、门诊缴费等服务。

- 
**支持绑定在其他医院办理的佛山健康卡，****支持绑定国家电子健康卡**。

- 
如果绑卡不成功，可能是由于您之前办理健康卡时填写的证件号与现在填写的身份证号不一致导致的，您可以到挂号处修改资料后再绑卡；也可能是由于您之前办理健康卡时填写的身份证号是15位的，您可以尝试填写以前15位的身份证号。

- 
如果需要解除绑定，请点击菜单【个人中心】->【我的信息】，然后点击已绑定健康卡的右上角“X”图标即可解除绑定。

- 
**如果7天内解除绑定操作超过3次，则将限制您继续绑卡。**

如何预约挂号

- 
点击菜单【服务中心】->【挂号】，然后选择科室、医生和时间段，最后选择相应的诊疗卡进行确认微信支付，如果预约成功，则会接收到系统推送的预约挂号成功提醒消息。**预约成功后，不再需要现场取号，直接到各科室报到就诊。**

- 
您到各科室就诊时，请出示“预约挂号成功提醒”、“挂号成功提醒”等消息，或点击消息的查看全文，出示我的二维码。

- 
如果您想要快速预约近期接诊过的医生，则点击菜单“服务中心->预约挂号"，然后点击“我要复诊”，可以查看近期接诊过的医生，最后点击相应的医生进行预约挂号即可。

- 
如果您在预约挂号时微信支付成功，但未能挂号成功时，系统最迟将于5个工作日内原路退回款项给您，请注意核对微信支付的退款到账通知。

如何取消预约

- 
如果需要取消预约挂号，点击菜单【个人中心】->【我的信息】，然后点击“我的预约”，最后点击“取消预约”即可。或者点击“预约挂号成功提醒”消息查看全文，也可以进行取消预约操作。

- 
预约挂号后，非就诊日期当天可以自行取消预约挂号。**如果当天已是就诊日，则请移步到收费窗口办理退号。**

- 
当天挂号后，如果需要退号，请移步至挂号收费窗口办理。

- 
由于相关费用要原路退回，请使用原挂号缴费的微信进行取消预约。

如何候诊

- 
点击菜单【个人中心】->【我的候诊】可以查看排队等候信息

- 
如果您是挂儿科门诊、妇科门诊、产科门诊等科室的号，则需要提前安排好时间先到现场报到，然后护士再安排给医生就诊。为了保证良好的就诊秩序，请您听从现场工作人员的安排，谢谢合作

- 
儿科门诊：凭健康卡（佛山健康卡、国家居民健康卡）在儿科门诊（门诊楼1楼）门口的自助报到机上进行自助报到，报到成功后候诊

- 
妇科门诊：凭健康卡（佛山健康卡、国家居民健康卡）在妇科门诊（门诊楼2楼）门口的自助报到机上进行自助报到，报到成功后候诊

- 
产科门诊：凭健康卡（佛山健康卡、国家居民健康卡）和产检病历本到产科门诊（门诊楼5楼）的护士站报到处进行报到

- 
**支持微信报到：**点击挂号成功消息，根据提示授权同意获取你的地理位置，然后点击“现场签到”，最后根据系统提示进行候诊。

如何缴费

- 
点击菜单【服务中心】->【门诊缴费】，然后选择已绑定健康卡，最后支付结算费用即可

- 
查看“待缴费提醒”的消息，可以进入缴费页面，仅支持**当天开单**的处方进行缴费，非当天开单的处方请移步到窗口办理

- 
门诊缴费支持禅城区居民医保结算。进入待支付界面时是显示总金额，点击“确认支付”后系统会计算居保统筹支付金额，最后再确认个人支付费用

- 
微信缴费不支持使用社保卡。如需使用社保卡，请移步到自助机或收费窗口缴费

- 
如果您在微信支付成功后，但未能结算成功时，系统最迟将于7个工作日内原路退回款项给您，请注意核对。

如何索取发票

- 
如果您需要发票，请移步到收费窗口，凭健康卡（佛山健康卡、国家居民健康卡）办理

如何退费

- 
门诊缴费后如果需要退费，请先到收费窗口打印发票，然后再找医生确认退费，最后再到收费处退款。

如何取药

- 
凭健康卡（佛山健康卡、国家居民健康卡）到西药房、中药房取药

如何检查治疗

- 
凭健康卡（佛山健康卡、国家居民健康卡）和检查治疗单到各检查治疗科室报到

缴费成功后可以凭健康卡或出示微信上“我的二维码”进行就诊。

健康卡样式如下：

佛山健康卡

国家居民健康卡

**住院服务使用指南**
如何绑定住院号

- 
点击功能菜单【服务中心】->【住院服务】进入选择人员界面。如果您已绑定的健康卡已有住院记录，则自动显示此住院号供选择。

- 
如果提示“您暂未绑定住院号，请先绑定再操作”，则点击“添加住院号”，输入您的住院号、姓名、手机号，最后点击“确定提交”验证您的身份。

- 
如果需要取消绑定住院，请点击功能菜单【个人中心】->【我的信息】进入界面后即可解绑相应的住院号。

如何缴纳住院押金

- 
点击功能菜单【服务中心】->【住院服务】进入选择人员界面，选择相应的住院号，点击“确定”后进【我的住院】界面，可以查看预交金额和总费用，随时随地了解费用情况。

- 
点击【押金缴纳】进入押金缴纳界面，选择相应的充值金额，然后点击“押金缴纳”，最后输入微信支付密码即可。充值成功后将会收到押金缴纳成功提醒消息。

如何查看每日清单

- 
进入【我的住院】界面，点击【每日清单】进入每日清单界面，将显示昨天的费用情况。您也可以通过选择日期查看相应日期的费用清单。
